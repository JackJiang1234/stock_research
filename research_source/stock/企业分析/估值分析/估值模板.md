# 价值投资股票估值模板补充文件（CSV+行业参数）

# 一、Excel可直接导入的CSV格式（分表格导出，复制粘贴至Excel即可）

## 1. 基础信息表（CSV）

```csv
字段,内容/公式,示例
股票代码,手动输入,600XXX
股票名称,手动输入,XX股份
所属行业,手动输入,消费/科技/银行等
当前股价（元）,手动输入,50.00
总股本（亿股）,手动输入,10.00
总市值（亿元）,股价 × 总股本,500.00
```

## 2. 定性评分表（CSV）

```csv
维度,权重,评分标准（1-5分，5分最优）,得分,加权得分（得分×权重）
商业模式（赛道+盈利）,30%,5分：万亿赛道+轻资产+现金流好；3分：中等赛道+平衡资产；1分：夕阳赛道+重资产+应收高,,
竞争壁垒（护城河）,30%,5分：多维度壁垒（品牌+专利+网络效应）；3分：单一壁垒；1分：无壁垒，竞争激烈,,
管理层与治理,20%,5分：经验足+资本配置优+无违规；3分：一般，无明显问题；1分：频繁违规+股权混乱,,
财务健康度,20%,5分：低负债+现金流持续为正；3分：负债适中+现金流波动小；1分：高负债+现金流为负,,
综合定性得分,-,加权得分求和,,
定性结论,-,≥4分：优质标的，继续估值；3-4分：一般，谨慎估值；＜3分：排除，不估值,-,-
```

## 3. DCF基础参数表（CSV）

```csv
参数,说明,取值建议,示例
预测期（年）,高速增长期年限,3-5年,5年
高速增速（g1）,前N年营收/利润增速,匹配行业增速,15%/12%/10%/8%/6%
稳定增速（g2）,永续增长率,≤GDP增速（2%-4%）,3%
折现率（WACC）,无风险利率+风险溢价,8%-12%,10%
基期经营现金流（亿元）,最近12个月经营现金流,手动输入,20.00
资本开支率,资本开支/经营现金流,成熟企业20%-40%,30%
营运资本增加率,营运资本增加/经营现金流,一般10%-20%,15%
```

## 4. DCF自由现金流计算表（CSV）

```csv
年份,经营现金流（亿元）,资本开支（亿元）,营运资本增加（亿元）,FCF（亿元）公式：经营现金流-资本开支-营运资本增加
第1年,基期×(1+g1),经营现金流×资本开支率,经营现金流×营运资本增加率,
第2年,第1年×(1+g1),同上,同上,
第3年,第2年×(1+g1),同上,同上,
第4年,第3年×(1+g1),同上,同上,
第5年,第4年×(1+g1),同上,同上,
```

## 5. DCF现值与终值计算表（CSV）

```csv
项目,公式,结果（亿元）
预测期FCF现值和,Σ[FCF第n年/(1+WACC)^n]（n=1-5）,
终值（TV）,FCF第5年×(1+g2)/(WACC-g2),
终值现值,TV/(1+WACC)^5,
企业内在价值（亿元）,预测期现值和 + 终值现值,
每股内在价值（元）,企业内在价值/总股本,
```

## 6. 相对估值表（CSV）

```csv
指标,公式,自身值,行业均值,历史3年分位,结论
市盈率（PE-TTM）,总市值/最近12个月净利润,,,,"＜30%：低估；30%-70%：合理；＞70%：高估"
市净率（PB）,总市值/净资产,,,,"＜30%：低估；30%-70%：合理；＞70%：高估"
市销率（PS-TTM）,总市值/最近12个月营收,,,,"＜30%：低估；30%-70%：合理；＞70%：高估"
PEG,PE/净利润增速（3年复合）,,,-,"＜1：低估；1-1.5：合理；＞1.5：高估"
```

## 7. 安全边际表（CSV）

```csv
项目,公式,标准,结果
安全边际,（每股内在价值-当前股价）/每股内在价值×100%,成熟企业≥30%；成长企业≥40%；高风险≥50%,
投资结论,-,达标：可关注；不达标：放弃,
```

## 8. 风险评分表（CSV）

```csv

财务风险（负债/现金流）,40%,,,

```


## 使用说明

1. CSV导入方法：复制对应表格的CSV代码，打开Excel→新建工作表→粘贴→选择“数据”→“分列”→分隔符选“逗号”，即可生成可编辑表格；

2. 行业参数使用：根据标的所属行业，直接填入DCF模板对应参数，无需自行测算，大幅提升估值效率；

3. 特殊说明：若标的为周期股（如钢铁、煤炭），可参考银行行业参数，调整高速增速为周期平均增速，资本开支率上调至30%-35%。
