# 通用股票企业价值链完整分析提示词
作为价值投资视角下的企业深度分析，需围绕“价值创造、竞争优势、可持续盈利”核心目标，全面拆解目标企业价值链的全维度要素，结合行业特性与企业业务实质展开穿透式分析，具体框架与要求如下：

## 一、价值链整体框架梳理
1. 明确{企业名称}核心业务定位与盈利模式，勾勒价值链的完整轮廓（含内部价值活动链条、外部关联方生态）；
2. 界定价值链的核心产出（产品/服务），以及价值从创造到传递、变现的全流程逻辑；
3. 对标行业平均水平与头部企业，初步判断{企业名称}价值链的整体复杂度、独特性与效率水平。

## 二、内部价值链深度分析
1. 拆解内部价值链的关键活动模块（如研发设计、原材料采购、生产制造/服务交付、市场营销、渠道分销、客户服务、后台支撑等）；
2. 分析各模块的价值贡献度（如研发对产品差异化的支撑、生产对成本控制的影响），明确核心价值创造环节；
3. 评估各环节的运营效率（如生产周转率、研发投入转化率、渠道触达效率）与成本结构（固定成本/变动成本占比、单位成本控制能力）；
4. 识别内部价值链的资源配置逻辑（技术、人才、资金、数据等核心资源向哪些环节倾斜），以及资源利用的合理性；
5. 排查内部价值链的衔接痛点（如研发与生产脱节、销售与库存不匹配），判断流程协同效率。

## 三、外部价值链生态分析
1. 梳理外部价值链的核心关联方（上游供应商、下游经销商/客户、合作伙伴、行业监管机构等）；
2. 分析与上下游的合作模式（如长期战略协议、市场化采购/销售、独家合作、股权绑定等），评估对上下游的议价能力（如采购成本优势、销售定价权）；
3. 判断外部价值链的稳定性（如供应商集中度、客户集中度、替代供应商/客户的可获得性）；
4. 分析行业政策、技术变革、宏观经济等外部因素对{企业名称}外部价值链的冲击与影响；
5. 评估{企业名称}在行业价值链中的定位（如龙头主导、跟随者、细分环节专业化玩家），以及对生态资源的整合能力。

## 四、关键环节与核心资源分析
1. 锁定价值链中具备“不可替代性、稀缺性、难以复制性”的关键环节（如核心技术研发、独家渠道、规模化生产基地、品牌运营等）；
2. 分析支撑关键环节的核心资源（如专利技术、核心团队、品牌口碑、数据资产、特许经营权等），评估资源的壁垒强度与可持续性；
3. 论证关键环节与核心资源的匹配度，以及二者共同构建的{企业名称}竞争护城河（如技术+渠道双壁垒、品牌+成本控制优势）；
4. 预判关键环节与核心资源的潜在风险（如技术迭代淘汰、核心人才流失、资源获取成本上升）。

## 五、价值链设计合理性评估
1. 结合{企业名称}战略定位（成本领先、差异化、聚焦细分市场等），判断价值链布局是否与战略目标一致（如成本领先战略下是否优化了生产与采购环节的成本结构）；
2. 对比同行业企业，分析{企业名称}价值链设计的差异化优势（如更短的流通环节、更高效的研发-生产闭环）或劣势（如冗余环节导致的成本高企）；
3. 评估价值链设计对市场需求变化的适配性（如是否能快速响应消费升级、个性化需求）；
4. 判断价值链的扩展性（如是否能通过延伸价值链进入高附加值环节、拓展新业务场景）。

## 六、内外部价值链协同性分析
1. 分析内部各环节的协同效率（如研发成果向生产转化的周期、生产计划与销售订单的匹配度、库存管理与供应链的衔接）；
2. 评估内部价值链与外部上下游的协同效果（如与供应商的联合研发、JIT生产模式的落地、对客户需求的快速响应机制）；
3. 量化协同效应带来的价值提升（如成本节约比例、交付周期缩短时长、客户满意度提升幅度）；
4. 识别协同不足的症结（如信息不对称导致的库存积压、外部合作流程繁琐影响效率），以及对{企业名称}盈利的负面影响。

## 七、价值链节点价值与成本穿透分析
1. 拆解各关键节点的价值创造能力（如各产品/业务线的毛利率、单客户LTV、节点贡献的营收占比）；
2. 分析各节点的成本构成（直接材料、直接人工、制造费用、营销费用等），以及成本控制的核心措施与效果；
3. 评估节点间的价值传导效率（如上游成本波动向下游的传导能力、核心环节的价值能否有效转化为终端溢价）；
4. 识别价值流失环节（如低效的渠道环节、不必要的中间成本），以及优化的可行性与空间。

## 八、价值链风险与长期优化空间分析
1. 基于前述分析，梳理价值链的核心风险（如供应链中断风险、关键环节技术被替代风险、政策变化导致的外部协同失效、成本上升压力）；
2. 评估{企业名称}针对上述风险的应对策略与抗风险能力；
3. 预判未来价值链优化的核心方向（如数字化转型提升效率、产业链整合增强控制力、全球化布局分散风险、技术升级强化关键环节壁垒）；
4. 分析优化措施对{企业名称}长期价值的影响（如盈利能力提升幅度、竞争优势巩固周期、估值逻辑的变化）。

## 九、价值投资结论推导
1. 整合上述分析，判断{企业名称}价值链的核心竞争优势是否具备可持续性；
2. 评估价值链的价值创造能力与{企业名称}当前估值的匹配度；
3. 给出明确的投资视角结论（如长期看好、谨慎乐观、回避），并列明核心依据（如价值链壁垒坚实支撑长期盈利、协同不足导致盈利韧性不足等）；
4. 提示关键跟踪指标（如核心环节毛利率变化、协同效率改善数据、风险事件进展等）。

## 分析要求
1. 需结合{企业名称}的行业属性、业务特性展开具体分析，避免泛泛而谈；
2. 尽可能结合量化数据（如财务报表数据、行业对标数据、企业运营数据）支撑分析结论；
3. 聚焦“价值创造”核心，穿透现象看本质，避免被短期业绩波动掩盖价值链的长期趋势；
4. 兼顾短期风险与长期潜力，平衡定性分析与定量论证。
