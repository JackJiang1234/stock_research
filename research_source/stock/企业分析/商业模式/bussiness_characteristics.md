# 通用股票企业生意特性深度分析提示词

**分析对象：{企业名称}**

作为价值投资分析基础，需围绕{企业名称}核心生意逻辑，从以下维度开展全面、穿透式分析，既要明确现状特征，也要预判长期稳定性与增长潜力，为投资决策提供底层依据：

## 一、产品/服务核心特性分析

1. 核心产品/服务的核心功能的是什么？是否解决了用户真实、刚性需求？需求频次（高频/低频）如何？
2. 产品/服务的物理特性（如耐用性、标准化程度、可复制性）或虚拟特性（如易用性、粘性）对生意模式有何影响？
3. 产品/服务的根基是否牢固？包括技术壁垒、专利保护、供应链掌控力、品牌认知度等竞争优势是否可持续？
4. 产品/服务的差异化程度如何？与竞品相比，核心竞争力（如性价比、性能、体验）是否显著且难以替代？
5. 产品/服务的迭代周期与迭代成本如何？是否需要持续大额投入以维持竞争力？

## 二、盈利模式特性分析

1. {企业名称}的核心盈利模式属于哪类？（产品差价型、服务收费型、订阅/会员型、金融利差型、广告变现型等，可多选并明确核心）
2. 该盈利模式的赚钱效率如何？体现为毛利率、净利率水平，是否处于行业合理区间且具备稳定性？
3. 盈利增长的驱动因素是什么？（量增、价涨、品类扩张、模式升级等）增长的可持续性与天花板如何？
4. 盈利模式是否依赖单一收入来源？多元化程度如何？单一来源波动对整体盈利的影响程度？
5. 盈利模式对外部环境（如政策、技术、消费习惯）的敏感度如何？是否存在盈利逻辑被颠覆的风险？

## 三、客户关系特性分析

1. {企业名称}与客户的关系类型属于哪类？（一次性交易、重复消费、长期绑定等）核心客户的复购率、留存率水平如何？
2. 客户转换成本（金钱成本、时间成本、学习成本）高低？高转换成本是否构成客户粘性的核心支撑？
3. 生意是否具备网络效应？（用户越多，产品/服务价值越高，进而吸引更多用户）网络效应的强弱与扩散边界如何？
4. 客户结构特征：核心客户群体（To C/To B/To G）是谁？集中度如何（是否依赖大客户）？客户需求的稳定性如何？
5. 客户获取成本（CAC）与客户生命周期价值（LTV）的比例是否健康？获客渠道的稳定性与效率如何？

## 四、成本结构特性分析

1. {企业名称}的成本结构以固定成本为主还是可变成本为主？两者的占比大致如何？
2. {企业名称}属于重资产模式还是轻资产模式？核心资产（固定资产、无形资产、人力资产等）的周转效率如何？
3. 是否具备规模经济效应？即随着营收规模扩大，单位固定成本是否持续下降，进而推动利润率提升？规模临界点在哪里？
4. 成本的核心构成是什么？（原材料、人力、租金、研发、营销等）核心成本的波动风险（如原材料涨价）是否可控？
5. {企业名称}的成本控制能力如何？与同行业相比，成本优势是否显著？成本优化的空间与路径是什么？

## 五、现金流特性分析

1. {企业名称}的现金流模式属于哪类？（预收款模式、账期模式、实收实付模式等）现金流与营收、利润的匹配度如何？
2. 经营活动现金流净额是否持续为正？是否能覆盖资本开支、分红等需求？现金流的质量（如是否依赖应收款回收）如何？
3. 账期模式下，应收账款的周转天数（DSO）、坏账率水平如何？是否存在回款风险？
4. 预收款模式下，合同负债（预收款）的规模与增长趋势如何？是否反映客户需求的真实热度？
5. {企业名称}的现金流对外部融资的依赖程度？是否具备自我造血能力？现金流断裂的风险点在哪里？

## 六、行业周期特性分析

1. 企业所处行业当前处于哪个发展阶段？（初创期、成长期、成熟期、衰退期）行业增长速度如何？
2. 行业的周期性特征如何？（强周期、弱周期、抗周期）周期波动的核心驱动因素（如宏观经济、政策、供需关系）是什么？
3. {企业名称}的经营业绩与行业周期的相关性如何？是否具备穿越周期的能力？应对周期波动的策略是什么？
4. 行业的竞争格局如何？（集中度高低、头部企业市占率、竞争方式是价格战还是差异化竞争）格局是否稳定？
5. 行业的长期发展空间受哪些因素制约？（市场容量、技术迭代、政策监管、消费升级/降级）未来10年行业趋势如何？

## 七、生意特性综合评估与风险提示

1. 综合上述维度，{企业名称}生意模式的核心优势是什么？（如高粘性、高壁垒、强现金流、抗周期等）
2. 生意模式的核心风险是什么？（如成本失控风险、客户流失风险、周期下行风险、技术颠覆风险、政策风险等）
3. 该生意特性是否支持{企业名称}实现长期、可持续的盈利增长？核心假设是什么？
4. 若未来行业环境发生重大变化，该生意模式的韧性如何？最可能被颠覆的环节是什么？

请基于以上框架，结合{企业名称}公开数据（财报、行业研报、公司公告）与行业常识，形成结构化、有数据支撑的分析结论，明确{企业名称}生意特性的优劣与长期投资价值核心逻辑。
